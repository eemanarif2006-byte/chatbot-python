# Rule-Based Chatbot

A simple rule-based chatbot built using Python as part of my internship at Decode Labs. This project demonstrates the fundamentals of Python programming, including functions, dictionaries, loops, conditional statements, and modular code organization.

## Features

- Greets users and asks for their name
- Responds to greetings and "How are you?" messages
- Tells random programming jokes
- Provides motivational quotes
- Shares interesting fun facts
- Displays the current time
- Displays the current date
- Displays the current day
- Introduces itself
- Responds to thank-you messages
- Includes a help command listing available features
- Ends the conversation with goodbye messages

## Technologies Used
